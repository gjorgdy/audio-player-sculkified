# AudioPlayer Expanded

AudioPlayer Expanded is a fork of the AudioPlayer mod by [henkelmax](https://github.com/henkelmax).
This fork adds support for the [Sculk Radio](https://github.com/gjorgdy/Sculk-Radio) mod and in the future the [JukeboxBoat](https://modrinth.com/mod/jukeboxboat) mod.

This mod can be installed server side as a replacement for AudioPlayer.
This means you still need to have Simple Voice Chat installed on the client and server.

## Features

---

- Being able to use custom music discs with Sculk Radio networks.
- (Coming Soon) Being able to use custom music discs with Jukebox Boats.
